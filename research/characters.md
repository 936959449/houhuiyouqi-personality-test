## B. 八位嘉宾

**B1 许飞**｜歌手，2006《超级女声》同届（媒体记为第五/第六）[R9]
- 关系史：厉娜称私下解约、跳槽规划被许飞转告公司，随后**被雪藏近七年、收到三封律师函**；许飞否认，先说"记不清了"，另一稿记她承认"可能话赶话漏了嘴"。[R1][R9][R10]
- 证据：小屋对坐**半分钟无人开口**，厉娜先破冰；被"我都不忍心了"击穿后喊出"**我画地为牢，厉娜**"；委屈不是被冤枉，而是"连一句'我没告密'都没人愿意听"[R9]。金句："**你对我的所有指控，我也都收到了，无论那些罪名是否属实，我想你当时一定都非常心碎。**"[R6]
- 争议：被视为最不可能和解的一组；"告密"无录音与第三方证词，属**未证实的罗生门**；"炒作说""打高层"为**网传**。[R10][R25]
- 关键词：隐忍的记名者 / 高浓度自省 / 缺席十五年的辩白 / 把牢底坐穿
- 八维 **Ti**：她把"罪名是否属实"当成唯一可处理的问题，情绪在心里算完才决定开不开口；沉默不是没话说，是证据链不闭合。九型 **4w5**：以"被误解的独特性"确证自我，羞耻驱动、向内收缩。

**B2 厉娜**｜歌手、演员，2006《超级女声》同届[R9]
- 关系史：同 B1。她要"经济损失的交代"，许飞要"你为什么不相信我"，两人"说的根本不是同一件事"。[R5][R9]
- 证据：**用具体事实说话**（三封函、七年空白、"于公于私于情于理我投许飞"、二十年前的 T 恤）；被问"恨过吗"答"**当然，非常久**"[R11]；软化是"**我都不忍心了**"——不是原谅，是耗不动了[R9]；反差名场面：听完"画地为牢"回房查词义，然后**点了份麦当劳**[R5]。
- 争议：因"受害者+叙事清晰+不卖惨"获大量共情；其叙述同样无第三方证据。
- 关键词：记账人 / 事实核对员 / 长期防御 / 温柔的终审
- 八维 **Si**：把十五年压成可复盘的细节档案，由过去的具体推出当下判断。九型 **6w5**：安全感建立在"可核对的确定"上，五翼把创伤转成资料。

**B3 马天宇**｜歌手、演员，与张萌因《幻城》相识[R12]
- 关系史：张萌转型制片人首部剧《白发》邀他演男主，他因父亲生病、状态差、角色不合婉拒；张萌气话"**我的戏，以后你都别来**"，他删掉其微信（一家人全删），断联近十年。[R12][R13]
- 证据：冲突处理是**不吵、切断**；社交自测**密友为零、好友两位**，情绪低落只能和 AI 聊天[R1]；落泪称"没有幸福感，也没什么欲望，常常陷入虚无"；金句"**人类好可怕，我要回郊区了**"，平时在郊区农场养鸡种菜[R1]。
- 争议：被视为"低电量社交"代表，也被批用"删好友"回避沟通；"七匹狼围攻""1v7"为**网传，节目组已辟谣**[R1]。
- 关键词：撤退者 / 空房间 / 自嘲的虚无主义者 / 低社交电量
- 八维 **Ni**：从删一次微信直接跳到"人类好可怕"的整体判断，习惯给关系找"企图/动机"的底层解释。九型 **9w1**：以回避冲突、缩小欲望换平静，"回郊区"就是麻醉动作。

**B4 张萌**｜演员、制片人，《白发》是其转型制片人第一部剧[R13]
- 关系史：同 B3。当年"初当制片人、正在兴头上"未体察好友状态，一句气话推倒关系；**2026 年由她主动邀约马天宇上节目**。[R13]
- 证据：**行动在前**（先发邀约再补解释）；看到对方崩溃当众自责[R12]；观察室替人拆解"不是你做人有问题，是人家不服气、嫉妒你"[R17]；玩笑"下次我帮你写序"后立刻道歉[R15]。
- 争议：被赞"成熟通达、会道歉"，也被认为那句气话造成实质伤害、道歉太晚。
- 关键词：破冰发起人 / 关系的项目经理 / 补偿型热情 / 自责式体贴
- 八维 **Fe**：注意力落在"场上气氛和别人状态"，用照顾、邀约、道歉重建共识，标准是"关系是否恢复和谐"。九型 **2w3**：靠"我为你做了什么"确认被需要，把修复关系当项目做。

**B5 王子璇**｜演员
- 关系史：2018 年作家文吉儿出书邀 20 岁的她写序，文吉儿主动提"圈内行情三四万"并转账**三万元**；同书另邀共友陆翊作序（免费、排序靠前）。八年后节目现场，文吉儿拿出**保存八年的转账记录与聊天截图**对质。[R14][R15][R22]
- 证据：**当场崩、次日清账**——落泪、退还三万、"不想做朋友了"，四组中唯一明确不和解[R15][R22]；"**我收费用是真的，虚荣心是真的，要面子是真的。但拼凑出来表述的那个人，不是真的我。我昨天非常狼狈，但是我不丢人，我直面了二十岁的自己。**"[R16]；回应"下次还会收费"[R15]。
- 争议：被赞真实，也被批把钱摆到友情前面；另有报道称她说"不记得收过"，与"退还三万"矛盾[R22]；店门口争吵被剪，被质疑放大冲突[R16]。
- 关键词：当场兑现 / 体面控 / 价格与情分分账 / 悬崖悟道
- 八维 **Fi**：核心是"哪个版本才是我"——她认具体行为，但拒绝被拼凑成不是自己的人；断交是对自我完整性的保护。九型 **3w4**：核心是"被怎么看"，反转本质是抢回体面。

**B6 文吉儿**｜作家、编剧，1996 年生，中国作协会员，中南大学本科、澳门大学硕博[R22]
- 关系史：同 B5。据节目与报道，她后来承认"三四万行情"是自己随口编的，共友陆翊免费作序；核心不是"收钱"，而是认知框架不同——她用"好朋友不该收钱"的逻辑，王子璇当成商务。[R14]
- 证据：**先存档、再对账、要结论**（凭证留八年）；不私下问，选择在有镜头处摊开[R14]。
- 争议：播出后成"众矢之的"之一，被批当众处刑朋友；网传其高中旧事、书籍推荐语风波（有教授公开否认写过）**均为网传，不得写入题目**[R22]。
- 关键词：存档者 / 规则审计员 / 对质型真诚 / 需要一个说法
- 八维 **Te**：把关系处理成可核查流程——留证、对账、给结论，标准是"按规则怎么算"，伤害性来自程序正义。九型 **1w2**：怨气源于"你违背了正确做法"，二翼让"纠正"带上道德正当性。

**B7 白小纯**｜本名陈礼根，2005 年生，PEL 和平精英职业联赛选手，天霸青训出身，后转会[R17]
- 关系史：与青稚同岁同青训、同吃同住四年；2024-05-19 PEL 春季赛总决赛天霸夺冠，青稚 FMVP、白小纯最佳新秀，并称"**天霸双子星**"。青稚认为他训练松散，**不直接沟通而找管理层督促**，话被传成"青稚说你人品不行"；2024 年 12 月青稚打招呼被无视，当晚直播称"我和他是不可能再和好的了"（"铁幕演说"）；白小纯被挂牌转会、辗转童家堡，断联约两年。[R17][R18]
- 证据：要的不是"催训练"的解释，而是青稚亲口确认那句"人品不好"；心结卡写"**每天训练像坐牢一样很恐怖**"；饭桌直球"**我现在不想和好，现在我不可能原谅**"，拒绝"鞠躬+拥抱"的破冰剧本；"**承认了，这就已经够了，我也不需要道歉**"[R17]。
- 争议：被赞"不配合表演和解的真活人"，也被批当众清算；四组中仅电竞组"半和好"[R19]；"买通队医""1v7"为**网传，节目组已辟谣**[R1]。
- 关键词：当场顶回去 / "被否定人品"的伤口 / 拒绝台阶 / 不原谅的诚实
- 八维 **Se**：痛感和反应都在当下——当场顶回去、当场倒完、当场拒绝台阶；"现在我不想和好"就是此刻的真实。九型 **5w6**：能量有限、惯于抽离，被侵入后彻底关门。

**B8 青稚**｜本名张庆波，2005 年生，PEL 职业选手，2024 PEL 春季赛总决赛 FMVP[R17]
- 关系史：同 B7。出发点是"希望身边人跟自己一样拼"，方式是找领导督促，结果被传成"说白小纯人品不行"；对账才发现中间人传话放大了问题。[R17][R18]
- 证据：**多线程、想到就做**（不先沟通就升级到管理层）；先鞠躬道歉、再被追着对账，被问"为什么都要归功到我身上"当场懵；**蒙绿毯子躲进卫生间哭**，后抱被子搬出双人间睡沙发；自评"**没边界感**""**不成熟**"，并称"**除了游戏，现实中我和他挺处得来**"[R17]。
- 争议：被视为"更愿意成长的那个"，也被批公开聊训练细节引粉丝网暴是越界。
- 关键词：没边界感的直给 / 多线程解释者 / 迟到的道歉 / 想回到轻松相处
- 八维 **Ne**：解法总是"还有别的可能"，话题跳得快、边界感弱，失误不是不在乎而是同时摊开太多可能。九型 **7w6**：用行动与解释快速翻篇、回避沉痛。

# 后会友期 · 人格拼图

> 32 道关于“走散的友情”的选择题，换一张只属于你的《后会友期》人格票根。

**🔗 在线体验：https://936959449.github.io/houhuiyouqi-personality-test/**

---

## 这是什么

一个基于芒果TV综艺《后会友期》8 位旅程嘉宾的网页趣味测试。

- **32 道题，约 5 分钟**：围绕“你和一位走散的旧友 TA，一起参加 18 天高原列车旅行”展开；
- **结果是一句话**：`人物 + 节目里的具体时刻`，例如 **许飞「悬崖小屋版」**、**王子璇「露天烧烤版」**、**白小纯「道歉现场版」**；
- **每个结果配一句本人台词**：名字下方会给出该人物在那个场景里说过（或写下）的话，并标注来源类型：节目原话 / 媒体转述 / 书面 / 节目外 / 网友配文；
- **24 种组合**：8 位人物 × 每人 3 个专属的节目时刻（想修复 / 还没想好 / 想告别），组合名互不重复。

## 结果页有什么

1. **人格拼图**：组合名 + 台词 + 台词出处；
2. **判词**：解释“为什么是你 + 这句话”；
3. **人物关系**：你最容易和谁走散、最想依赖谁；
4. **三层拼图**：本我位（人物与八种心智能量）、关系位（关系姿态与关系身份）、社会位（九型动机与行动风格）；
5. **数据卡**：心智能量雷达、九型动机、关系行动；
6. **结局预测**：按“想修复 / 还没想好 / 想告别”给出结局文案，附一句可以复制发给旧友的话。

## 计分是怎么来的

测试不直接问“你是什么类型”，而是从三套公开的人格框架取材，藏进情境题里：

- **八种心智能量**（荣格八种心理功能）：决定你像 8 位人物中的哪一位；
- **九型动机**：决定你在关系里的核心驱动力；
- **关系行动**：4 种行动风格 × 修复/告别倾向，决定你在这趟关系里的姿态，进而决定你落到人物的哪个“节目时刻”。

最终只输出一个组合，不输出任何字母类型标签；**这不是心理学测评，也不构成任何诊断**。

- 纯静态站点：HTML + CSS + 原生 JavaScript，无构建、无后端依赖；
- 托管在 GitHub Pages，`main` 分支推送后自动发布 `site/` 目录；
- 本地预览：

```bash
# 打开 http://localhost:8000/site/
```
